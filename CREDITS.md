# Sample sources (personal, non-commercial use)
Samples were fetched with the scripts in `tools/` from these public collections. Licences differ and were not all independently verified, so check each source before ever using the app for anything other than personal use.
- Versilian Community Sample Library (VCSL): upright piano, recorder, tenor sax, tubular bells, hand chimes, wine glasses, timpani, cajon, shakers, bongos and more.
- VSCO 2 Community Edition: string section, pizzicato strings, oboe, piccolo, hand percussion.
- Mellotron samples (flute, strings, choir) via the danigb/samples collection. Licensing unclear.
- jRhodes3d Rhodes electric piano via danigb/samples. Stated as non-commercial use only.
- Wurlitzer EP200 (gs-e-pianos) via danigb/samples.
- dsmolken double bass.
- Drum machines (TR-808, LinnDrum, CR-8000, Drumtraks, RZ-1) via danigb/samples.
- MusyngKite soundfont samples via gleitz/midi-js-soundfonts: celesta, clavinet, drawbar organ, accordion, pan flute, shakuhachi, muted trumpet, choir, sitar, banjo, koto, shamisen, dulcimer, steel drum, slap bass, jazz guitar, music box.
- Original instruments from the first version of Jam Room (piano, strings, winds, etc.).
